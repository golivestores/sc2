滚动背景变色

CSS 变量重定向、主导区块判定、Lenis 平滑滚动，让整页背景色和文字色随滚动连续过渡。

Implementation Notes

随滚动平滑切换背景色的实现说明

页面由多个整屏区块组成。向下或向上滚动时，整页的背景色、文字色、边框色会随“当前主导区块”平滑切换，过渡时长约 0.6s。

效果描述

页面由多个整屏区块组成。向下或向上滚动时，整页的背景色、文字色、边框色会随“当前主导区块”平滑切换，过渡时长约 0.6s，不是瞬间硬切。

一、架构原则

不要用 JS 逐帧计算颜色来做动画。采用三层解耦：

  1. CSS 只定义一组“原色盘”常量，也就是写死的具体颜色。
  2. 元素只引用“语义变量”，如 --clr-base-primary，这些语义变量在 CSS 里不赋具体值。
  3. JS 只负责一件事：根据当前主题，把语义变量在 :root 上重新指向不同的原色变量。过渡由 CSS transition 完成。

这样 JS 每次滚动只翻转几个变量，开销极小；所有引用这些变量的元素靠 CSS 一起补间，同步且连续。

二、颜色与主题定义

原色盘放在 :root：

:root{
  --clr-obsidian:#1f1303;   --clr-cashmere:#746756;   --clr-mauve:#baa996;
  --clr-ecru-type:#e7dbc6;  --clr-ecru-bg:#f3e7d1;    --clr-off-white:#fffcf6;
  --clr-stroke-light:#bbaa9666;  --clr-stroke-dark:#bbaa964d;
}

三种主题 light / mid / dark。每种主题下“语义变量 → 原色”的映射：

语义变量lightmiddark
--clr-base-primary（主背景）off-whiteecru-bgobsidian
--clr-base-secondary（反色块背景）obsidianobsidianoff-white
--clr-content-primary（主文字）obsidianobsidianoff-white
--clr-content-secondary（次文字）cashmerecashmeremauve
--clr-content-tertiarycashmerecashmereecru-type
--clr-border（边框）stroke-lightstroke-lightstroke-dark
--clr-invert（logo 反色开关，数值）001

三、HTML 结构

每个区块用 data-theme 标注它要触发的主题：

<section data-theme="dark">...内容...</section>
<section data-theme="light">...</section>
<section data-theme="mid">...</section>

区块内容使用语义变量，并挂上 transition：

section{
  background-color:var(--clr-base-primary);
  color:var(--clr-content-primary);
  min-height:100vh;
  transition:background-color .6s ease-out, color .6s ease-out;
}
.divider{
  border-color:var(--clr-border);
  transition:border-color .6s ease-out;
}

凡是用到这些语义变量的元素，包括 header、按钮、边框、文字等，都要挂上对应属性的 transition: ... .6s ease-out，否则那部分会瞬间跳变。

四、主题切换器（核心）

const THEMES = ["light","mid","dark"];
const MAP = {
  "base-primary":     {light:"off-white", mid:"ecru-bg",     dark:"obsidian"},
  "base-secondary":   {light:"obsidian",  mid:"obsidian",    dark:"off-white"},
  "content-primary":  {light:"obsidian",  mid:"obsidian",    dark:"off-white"},
  "content-secondary":{light:"cashmere",  mid:"cashmere",    dark:"mauve"},
  "content-tertiary": {light:"cashmere",  mid:"cashmere",    dark:"ecru-type"},
  "border":           {light:"stroke-light", mid:"stroke-light", dark:"stroke-dark"},
  "invert":           {light:0, mid:0, dark:1},
};

let current = null;
function applyTheme(name){
  if(current === name) return;
  current = name;
  const root = document.documentElement;
  for(const [key, byTheme] of Object.entries(MAP)){
    const raw = byTheme[name];
    const val = typeof raw === "string" ? `var(--clr-${raw})` : String(raw);
    root.style.setProperty(`--clr-${key}`, val);
  }
}

五、判定“当前主导区块”

不要一进视口就切换。用带滚动方向的加权打分，选出得分最高的区块：

let lastY = window.scrollY;
function update(){
  const goingDown = window.scrollY > lastY;
  lastY = window.scrollY;
  const vh = window.innerHeight;
  let best = -1, winner = null;

  document.querySelectorAll("[data-theme]").forEach(el=>{
    const r = el.getBoundingClientRect();
    const visible = Math.max(0, Math.min(vh, r.bottom) - Math.max(0, r.top)) / r.height;
    if(visible <= 0.1) return;

    let score;
    if(goingDown){
      const dist = Math.abs(vh/2 - (r.top + r.height/2));
      score = visible - dist/vh*0.3;
      if(visible > 0.6) score += 0.2;
    }else{
      score = r.top <= 0 ? visible + 0.5 : visible + (1 - r.top/vh)*0.7;
      if(visible > 0.5) score += 0.3;
    }
    if(score > best){ best = score; winner = el; }
  });

  if(winner) applyTheme(winner.dataset.theme || THEMES[0]);
}

六、触发方式与平滑滚动

  • 用 IntersectionObserver（阈值分档 [0,.25,.5,.75,1]）观察所有 [data-theme] 元素，回调里调用 update()，作为进出视口的兜底触发。
  • 原生滚动在部分系统，尤其 Windows 上是阶梯式步进，会让加权评分跳变。引入平滑滚动库 Lenis 或等价方案，并在其 RAF 回调里也调用 update()，让评分随滚动连续更新。
const observer = new IntersectionObserver(update, {threshold:[0,.25,.5,.75,1]});
document.querySelectorAll("[data-theme]").forEach(el=>observer.observe(el));

const lenis = new Lenis();
function raf(t){ lenis.raf(t); update(); requestAnimationFrame(raf); }
requestAnimationFrame(raf);
update();

七、验收标准

  1. 慢速上下滚动时，背景、文字、边框在约 0.6s 内平滑补间，无闪烁、无瞬间跳变。
  2. 主题切换发生在区块占据视口中部时，而不是刚露头就切。
  3. 同一主题的连续多个区块滚动时不重复触发，由 applyTheme 的去重保证。
  4. 引入 Lenis 后滚动连续、变色连贯；移除 Lenis 会明显变卡，可据此确认平滑滚动生效。

技术栈

  • 核心：CSS 自定义属性重定向 + CSS transition 补间，非 JS 逐帧动画。
  • 依赖：Lenis（平滑滚动）+ IntersectionObserver（浏览器原生）。
  • 颜色主题、过渡时长、加权参数均可按需调整。
